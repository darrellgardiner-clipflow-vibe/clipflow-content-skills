# Brand Lens: understand the brand

Read [the shared handoff](../clipflow-content/references/handoff.md) and select the appropriate path from [sources](../clipflow-content/references/sources.md). For an existing project, also use [project integration](../clipflow-content/references/project.md).

1. Resolve the business, speaker, account and requested goal from existing project context. Ask when identity is ambiguous; never merge similar handles or client voices.
2. Read the existing project brief and supplied brand rules before inferring new ones. Extract relevant passages and their locations from source documents, posts and transcripts. Inspect original passages for the claims intended for use.
3. Fill the brand fields from the shared handoff. Separate owner instructions, observed habits, supported facts, historic statements and proposed interpretations. Record conflicts and currentness instead of choosing whichever appeared most often.
4. Describe voice through examples and decisions: how the person opens, explains, qualifies, disagrees and asks for action. Preserve distinctive wording. Sparse samples mean provisional voice, not permission to invent a personality.
5. Identify usable proof and perspectives for the requested content. When applying a viewpoint to a new question, show the reasoning and label an extrapolation as proposed; do not invent a first-person opinion or retell the same origin story in every piece.
6. Save or update the existing project brief with evidence IDs and material gaps. Highlight only questions that change the next deliverable. Keep a useful partial brief when an optional detail is missing.

Output: the working brand brief, a source/coverage note and the inputs needed for the requested next stage. Continue to [planning](../clipflow-plan/SKILL.md) or [writing](../clipflow-write/SKILL.md) when requested. Keep the working brand knowledge in the existing project brief, with links to original evidence. Refresh relevant fields when sources or owner corrections change; preserve the reason and date. Do not duplicate the source archive or update connected account data outside the requested scope.
